# 🧠 Skills del Proyecto Viajes

Skills especializadas por área del sistema. Cada skill define objetivo, cuándo aplicarla,
instrucciones clave y anti-patrones.

## Índice

| Archivo | Área | Fases |
|---|---|---|
| `nestjs-backend.md` | Backend NestJS | 1–11 |
| `prisma-postgres.md` | Base de datos | 1, 3, 4, 6, 10 |
| `react-vite-frontend.md` | Frontend React + Vite | 3, 7, 10–11 |
| `mercadopago-integracion.md` | Pagos Mercado Pago | 5 |
| `seguridad-web.md` | Seguridad web | 2, 5, 11 |
| `testing-jest-playwright.md` | Pruebas | 2–11 |

## Uso

- El **Lead Arquitecto** referencia los skills al asignar tareas.
- Cada **agente especializado** carga el skill correspondiente a su área antes de implementar.
- Los skills se actualizan cuando el roadmap evoluciona una decisión técnica.
